Windows macOS Linux

First launch warnings (the app isn't signed)

Windows: unzip, run Shooter.exe. If "Windows protected your PC" appears: More info → Run anyway.

macOS: unzip and move Shooter.app to Applications. Right-click it → Open → Open. If macOS still refuses: System Settings → Privacy & Security → Open Anyway, or in Terminal: xattr -cr /Applications/Shooter.app

Linux: chmod +x Shooter-Linux.AppImage, then run it.
